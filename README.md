# mammoth-xp .docx to HTML converter
A fork of mammoth-plus with additional DOCX formatting support.

Additional features:
- Preserve font size when converting DOCX to HTML


## Installation

    npm install mammoth-xp

## Usage

### Library

mammoth-xp can be required/import in the usual way:

```javascript
var mammoth = require('mammoth-xp')
// or
import mammoth from 'mammoth-xp'
```
